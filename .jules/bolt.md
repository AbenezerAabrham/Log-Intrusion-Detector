## 2026-07-21 - Optimizing Log Intrusion Detection Loop in LogWatch
**Learning:** In a client-side log intrusion detection tool (like LogWatch), iterating over high-frequency logs requires a single-pass loop design. Instantiating regular expressions and calling `Object.entries()` inside the loop introduces heavy allocation overhead and slow execution. Converting iterations to standard index-based `for` loops, pre-calculating array representations of static dictionaries, and lazy-initializing dynamic arrays (like `flaggedReasons`) reduces memory pressure and execution time significantly.
**Action:** Always hoist static regexes and dictionary mappings outside performance-critical loops. Convert high-frequency iterations to standard index-based `for` loops, and avoid creating intermediate arrays (such as through `.filter()` or `.forEach()`).
