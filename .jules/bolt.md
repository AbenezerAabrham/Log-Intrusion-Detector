## 2026-08-02 - Hoisting static patterns and converting to index-based loops in log parsing
**Learning:** In highly repetitive server-side and client-side log analysis functions, regex compilation and loop constructs like `.forEach` and `.filter` add considerable overhead. Hoisting static regular expressions and array conversion (like `Object.entries()`) to the outer module scope, coupled with sequential index-based `for` loops, avoids repeated memory allocation and reduces GC churn. Lazy initialization of local variables (such as arrays) inside inner loops also dramatically saves execution time.
**Action:** Always inspect tight performance-critical loops to hoist object/regex recreation out of function boundaries, replace higher-order iteration methods with sequential loops, and avoid allocating intermediate arrays.
