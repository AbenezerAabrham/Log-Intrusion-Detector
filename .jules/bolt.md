## 2026-08-13 - Optimizing Client-Side Log Analysis Engine via Loop Unrolling and Allocation Avoidance
**Learning:** In V8/NodeJS, high-frequency text parsing engines suffer majorly from helper array allocations (e.g., `.split().filter()`) and nested callback overhead (e.g., `.forEach()`). By restructuring the parser to process a single split array while handling non-empty checks, caching lookup targets, lazy-allocating arrays, and tracking aggregate metrics inline inside the loop, garbage collection overhead is minimized and V8 can highly optimize the execution path.
**Action:** Always avoid intermediate pipeline arrays (such as `.filter()`) and use sequential, index-based `for` loops in performance-critical code blocks. Track counts and metrics inline instead of executing multiple filters/reductions over the data afterward.
