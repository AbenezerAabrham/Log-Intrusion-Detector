## 2026-08-07 - Optimizing Tight Loops in Log Intrusion Detection
**Learning:** In client-side log analysis tools processing up to 100,000+ lines, high-frequency operations inside loops (such as regex instantiation, calling `Object.entries()` inside loops, and chaining `.filter().forEach()`) create significant memory and CPU overhead due to garbage collection and extra allocations. Hoisting constants/regexes and switching to flat arrays with sequential index-based `for` loops provides major execution speedups.
**Action:** Always hoist regular expressions, avoid inline object conversions (`Object.entries`), replace functional loop methods with index-based `for` loops, and cache repeated nested object accesses when dealing with larger datasets in performance-critical code.
